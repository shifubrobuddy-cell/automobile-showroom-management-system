## 🚀 Zero-Config Static Deployment (Vercel, GitHub Pages, Netlify)

This project is built with **Pure HTML5, CSS3, and Vanilla JavaScript (ES6+)** with **zero build steps, zero node dependencies, and zero backend servers**.

### Deploy on Vercel
1. Push this repository to **GitHub** (or export to GitHub via AI Studio Settings).
2. In [vercel.com](https://vercel.com), click **"Add New Project"** -> **"Import Git Repository"**.
3. **Framework Preset**: Select **"Other"** (Static Site).
   - Build Command: None (or leave blank)
   - Output Directory: `./` (Root directory)
4. Click **Deploy**. Your live automobile showroom management system will be live globally in 5 seconds!

*(Alternatively, you can also deploy instantly using the Vercel CLI by simply typing `vercel` in the project root).*

## 📦 System Modules & Capabilities

1. **Authentication & Session Security**: Role-based access with persistent session state and fast logout.
2. **Executive Overview Dashboard**: Real-time sales turnover, inventory stock count, pre-orders pipeline, interactive revenue trend line charts, and fuel distribution charts.
3. **Vehicle Inventory Management**: Full vehicle catalog CRUD with brand, model, colour, fuel type, ex-showroom price, VIN, year, real-time status badges, search, filter, and CSV data export.
4. **Customer Relationship Directory (CRM)**: Individual and corporate client records, phone, email, PAN/GST numbers, linked order history, and customer CSV export.
5. **Pre-Orders & Booking Pipeline**: Booking schedule, token advance payments, delivery dates, booking status tracking, and 1-click conversion into sales invoices.
6. **Sales Invoicing & Automated Billing**: Automated tax invoicing with GST calculation, RTO fees, insurance charges, automated inventory decrement, and clean print-ready A4 layout (`@media print`).
7. **Executive Audit Reports**: Stock valuation audits, revenue turnover, customer lifetime value, and CSV export.
8. **Dual Theme Engine**: High-contrast, showroom-grade Dark Mode and Light Mode with instant toggle and persistent theme memory.
9. **Academic Project Info**: Interactive academic synopsis modal containing project details, guide credentials, and university affiliation.
